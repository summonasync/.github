# One dev. A swarm of agents. Nothing leaves the machine.

Local-first, Linux-first .NET tooling for developers who run an AI-agent crew
from one laptop. Download one binary, point it at your repo, summon the swarm.
No cloud, no API keys, no Docker quest.

## The kit

Four binaries. One summoner. Zero cloud.

| Tool | Layer | State |
|---|---|---|
| **Overmind** | Project intelligence — the planning board, decisions, gates and skill kits of one project. | runs daily · publishing soon |
| **Grimoire** | Global agents knowledge — one shared memory. Every agent. Every project. | v0.1.0 · publishing soon |
| **Squeezr** | Context compression — hybrid exact + semantic index, maximum meaning per token. | v1.0.9 · publishing soon |
| **Mindlash Studio** | Multi-agent workspace — launch, watch, gate and kill agent sessions. | coming soon |

## The story

Every tool here exists because one developer got tired of re-explaining his own
codebase to a language model. First came the board each project thinks on.
Then a memory that survives the session — and every other project. Then an
index that stopped the agents from reading whole files. Then a desk to run
them all from.

## The position

Context belongs on your disk, not in somebody's bucket. The moment your
codebase index, your agent memory and your planning board live on someone
else's server, you are renting your own thoughts back — with a network round
trip, a subscription, and a policy you did not write.

## What's ahead

The binaries exist and earn their keep on one machine every day. The repos are
not public yet — everything is being polished before the mirrors land here:
source, licenses, installers, changelogs. No empty repos, no mockup
screenshots, no vaporware links. A link appears when there is a binary behind
it.

Watch this org. The repos show up when the circle is drawn.

## Fine print

- **Bus factor of one. Swarm factor of many.** Issues may sit for a while;
  that is disclosed here so it does not have to be discovered later.
- **Local means local.** Loopback HTTP, files on your disk, no accounts, no
  telemetry — and therefore no team features and no hosted version of your
  memory.
- **.NET, Linux first.** One self-contained binary, no runtime install, no
  node_modules archaeology. Ubuntu is the first-class citizen — it is where
  these binaries are built and daily-driven. Windows rides along. The
  trade-off is honest: the runtime is Microsoft's.
- **No SaaS.** No team tier, no enterprise offering, no "free plan" that
  becomes a paid plan. If that ever changes, this section gets edited and the
  edit gets logged.
